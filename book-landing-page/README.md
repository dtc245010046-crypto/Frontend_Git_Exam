# Nếp Sống Tinh Gọn — Book Landing Page

Trang giới thiệu sách tĩnh, responsive, được xây dựng bằng HTML, CSS và Bootstrap 5.3.3. Các mục gồm Header, Book Overview, Author, Features, Prices, Download, Reader's Say và Footer.

## Chạy trang

Mở `index.html` trong trình duyệt. Bootstrap CSS/JS và Google Fonts được tải từ CDN; ảnh bìa sách và chương đọc thử nằm trong `assets/`.

## Tài nguyên

- `assets/book-cover.svg`: bìa sách minh họa tự dựng bằng SVG.
- `assets/sample-chapter.txt`: nội dung đọc thử có thể tải xuống.
- Giao diện tham khảo: [hoanv7169/bootstrap-demo](https://github.com/hoanv7169/bootstrap-demo).
