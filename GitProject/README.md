# GitProject

Chào mừng bạn đến với dự án **GitProject**!

---

## 1. Giới thiệu dự án
Đây là dự án thực hành bài tập **Sử dụng Git** trong chương trình đào tạo Frontend ICTU. Dự án nhằm mục đích:
- Làm quen và thực hành thành thạo các thao tác cơ bản với Git và GitHub.
- Nắm vững quy trình làm việc chuẩn: Khởi tạo/Clone Repository &rarr; Tạo file &rarr; `git add` &rarr; `git commit` &rarr; `git push`.
- Quản lý cấu trúc thư mục mã nguồn (`source/`) trên hệ thống kiểm soát phiên bản.

---

## 2. Cấu trúc thư mục dự án
```
GitProject/
├── README.md            # Tài liệu giới thiệu dự án
└── source/              # Thư mục chứa mã nguồn giao diện
    ├── index.html       # Trang chủ (Index Page)
    └── news.html        # Trang tin tức (News Page)
```

---

## 3. Các lệnh Git đã sử dụng
- `git clone <url>`: Sao chép kho lưu trữ về máy tính.
- `git add <file>` / `git add source/`: Đưa các tệp vào Staging Area.
- `git commit -m "Add README.md"` / `git commit -m "Add source files"`: Lưu trữ snapshot vào lịch sử Git.
- `git push origin <branch>`: Đẩy các thay đổi lên GitHub.
